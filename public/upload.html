connect to your site.

This app publishes straight to your GitHub repo, and GitHub Pages puts it on the site. One-time setup: give it a token that can write to the repo.

  1. On your phone, open github.com → new fine-grained token.
  2. Name it portfolio uploader. Under Repository access choose Only select repositories and pick Jamstand/just-be-making-stuff.
  3. Under Permissions → Repository permissions set Contents to Read and write. Leave everything else alone.
  4. Generate it, copy it, paste it below. It stays on this phone only.

To keep this as an app: open the share menu in Safari (or the ⋮ menu in Chrome) and tap Add to Home Screen.
