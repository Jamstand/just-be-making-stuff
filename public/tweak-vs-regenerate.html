Tweak
vs Regenerate.

Two ways the design changes after the first generation. One is free and instant — the other costs a round trip and a roll of the dice. Both belong in the loop. Knowing which to reach for is the whole game.

ATweak.

Sliders mutate the brand tokens. The page is the same page — same structure, same words, same shapes — repainted with different values. Instant. Free. Predictable.

Reach for Tweak when…

you like the design but want it warmer, tighter, darker, rounder. The brand color is wrong. The headline font is heavier than it should be. The radii are too sharp. The composition is fine — the surface isn't.

↓ same DOM · different CSS variables

Reach for Regenerate when…

the design itself isn't right. You want a timeline instead of a meter. A different hero. New sections. More content. The tokens are fine — the shape isn't. Pay the round trip; let the model rebuild from the brief.

↓ new DOM · same brief, fresh structure
