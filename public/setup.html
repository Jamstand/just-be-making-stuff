OBS Setup

  1. 1

    Add a Browser Source in OBS

    In OBS, click + in the Sources panel → select Browser.

  2. 2

    Paste the widget URL

    http://localhost:3000/widget.html
  3. 3

    Set dimensions & enable transparency

    Width: 400 Height: 120
    Check "Shutdown source when not visible"
    Check "Refresh browser when scene becomes active"

  4. 4

    Position the widget

    Drag the source to wherever you want the overlay — typically bottom-left or bottom-right of your scene.

Need a Spotify app? Create one for free at developer.spotify.com/dashboard — add http://localhost:3000/callback as a Redirect URI, then copy the Client ID and Secret into your .env file.
