Face Sweep needs a desktop Chromium browser.

This app reads and organises files directly on your computer, which needs the File System Access API. That is available in Chrome, Edge, Brave, Opera or Arc on Windows, macOS, Linux or ChromeOS. Firefox, Safari and mobile browsers can't do this yet.
