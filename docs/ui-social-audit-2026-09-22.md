# Crack a Geode! — Merged UI & Player-Interaction Audit

Synthesized from five read-only audit lenses (ui-ux, social, wiring, mobile-perf, benchmark) of the Rojo repo at `C:\Users\jameg\just-be-making-stuff` (byte-synced from Studio). Overlapping findings were merged; where lenses disagreed on line numbers the citation with the strongest evidence was kept. All paths are relative to `src/`. Severity: **HIGH** = blocks the brief's goals or is a live defect players hit; **MED** = visible quality/robustness gap; **LOW** = polish or latent risk.

Nothing in this report has been implemented. It feeds the implementation plan (contract + work packages for `server`, `clientUI`, `clientModules`).

---

## 0. Executive summary

The HUD/panel system works and has real strengths (responsive cap/scale fitting, claimable glow rings, hold-to-crack, replicated trophy orbits, server-side VIP visuals), but the audits converge on five root problems:

1. **UI.luau has drifted off the StyleGuide.** It never calls `SG.button/SG.panel/SG.label` (NexusFX does), uses 54 `Enum.Font.*` literals vs 2 `SG.Font`, ~30 raw `Color3.fromRGB` where tokens exist, off-token radii/strokes, and a one-shot "style pass" at Init that bakes stale strokes. HUD panels and Nexus world cards look like two different games. (`client/CrackAGeodeClient/UI.luau:44-56, 677-678, 1387-1402`; `client/CrackAGeodeClient/StyleGuide` tokens `shared/StyleGuide.luau:45-90`)
2. **Mobile ergonomics fail the game's own 48 px rule.** Close buttons 40/30 px, row buttons 40-46 px, then FitScale 0.85 on phones → 34-39 px rendered; the side menu's bottom row sits under the CoreGui jump button on every landscape phone; toasts spawn over the CRACK button; TextScaled labels drop to ~9 px. (`UI.luau:178, 232, 311, 1040-1060`; `shared/StyleGuide.luau:72-76` `MinTouch=48` never referenced)
3. **Standard affordances are missing.** No Escape/tap-outside/scrim, no Settings (music 0.22 hard-coded, no reduce-FX), no confirmation on Rebirth/Ascend which zero gems/power/luck on one tap, HUD balance hidden while any panel is open, first-join stacks a Daily modal over the onboarding geode. (`UI.luau:338, 477-478`; `server/CrackAGeodeServer/Econ.luau:190, 202`; `client/CrackAGeodeClient/Effects.luau:72`)
4. **Currency copy is split.** 17 user-facing "Coins/Coin" strings (Config passes/products, Shop section, pet bonus lines, VIP daily, Monetize grant messages, Nexus cards) vs "Gems 💎" everywhere else including leaderstats and the HUD icon. The same pet stat reads "+N% Gems forever" in the broadcast and "+N% Coins" in the panel. (`shared/Config.luau:16-36, 138`; `UI.luau:591, 865, 881, 1299`; `server/CrackAGeodeServer/Pets.luau:73`)
5. **Other players are nearly invisible.** The equipped pet is parented to `workspace.CurrentCamera` so nobody else sees it; the only overhead presence is the VIP crown; no Players panel, no feed (banners die in 4.5 s), boards are session-only top-8 walls with no own rank, the Meteor shows only an HP bar and broadcasts state on every tap (O(N²)), there is no cooperative goal, no reactions, no join greeting, chat tags are VIP-only. (`client/CrackAGeodeClient/PetView.luau:109`; `server/CrackAGeodeServer/Monetize.luau:53-90`; `server/CrackAGeodeServer/Boards.luau:2, 24-45`; `server/CrackAGeodeServer/Meteor.luau:179`)

Live defects found on the way (all reproducible from the code): orbit rings never broadcast on profile load so joiners are ring-less to everyone already online; `Pickaxe.Init` can park the whole server bootstrap; every client `InvokeServer` is unwrapped; two pickaxe swing systems fight over one weld; `EquipPet` throws on NaN; chip countdowns use client `os.time()` and ignore `snap.now`; zone skip-unlock products leak into the Shop despite the `zoneUnlock` flag; Signposts allocates `GetDescendants()` every frame; Orbit animates every ring every frame with no cull.

## 4. Constraint exclusions (from the brief)

- **No trading or any player-to-player value transfer** (gems, pets, boosts) — new value surface + dupe/scam risk. Keep Gift a Boost (Robux) and the free cosmetic Cheer.
- **No gem/coin rewards** for Premium/group membership, server goals, reactions, or redeem codes. Server goals and cheers pay out only the existing luck-buff primitives (`Buffs.AddServerGift`, `Buffs.GrantBoost`).
- **Codes panel deferred**; if ever added, buff-only, once-per-profile, ≤24-char type-checked string, 1 attempt per 3 s.
- **No new uploaded assets**; emoji fallbacks for sprout/gear/reactions.
- **No new per-frame work scaling with player count**: nameplates are engine-rendered BillboardGuis updated on attribute events; other players' pets on Heartbeat with nearest-N cap; feed/Players panel rebuilt on events with coalescing timers.

**Replicated Player attributes (server-set only):** `Rebirths:number`, `Ascensions:number`, `Zone:string` (from Regions 1 s loop, written on change), `PetName:string`, `PetEmoji:string`, `PetColor:Color3`, `IsVIP:boolean` (exists), `Title:string?`.
